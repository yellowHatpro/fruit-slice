# Fruit Slash

An original, lightweight 3D fruit-slicing arcade game built with Godot 4.

## Play

Open `project.godot` in Godot 4, or run:

```sh
godot --path .
```

Press **Start Run**, then drag the mouse (or swipe on a touch display) through
fruit. Missing three fruit ends the run; slicing a bomb ends it immediately.

All visuals and sounds in this prototype are generated at runtime from Godot
primitives and original procedural audio, so the project has no external asset
licensing requirements.
