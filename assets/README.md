# Assets

Fruit Slash uses original low-poly fruit, sliced-half, and bomb models created
in Blender through Blender MCP. Godot-ready exports are stored in `models/`,
and the editable workshop file is stored in `source/`.

Future source and exported assets belong in these tracked directories:

- `audio/` — original or verified open-license music and sound effects
- `models/` — Godot-ready GLB exports used directly by gameplay
- `source/` — editable Blender source files (excluded from Godot imports)
- `textures/` — textures and material inputs
- `vfx/` — reusable visual-effect resources

The current model set is original project work released as CC0 and uses no
third-party textures. Any future external asset must include its licence and
attribution metadata.
