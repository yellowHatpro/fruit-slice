# Assets

Fruit Slash currently generates its prototype fruit meshes, materials,
particles, and sound effects at runtime. This keeps the first playable build
self-contained and free from external licensing requirements.

Future source and exported assets belong in these tracked directories:

- `audio/` — original or verified open-license music and sound effects
- `models/` — Godot-ready GLB exports
- `textures/` — textures and material inputs
- `vfx/` — reusable visual-effect resources

Blender source files should be kept separately from exported GLB files, and any
third-party asset must include its licence and attribution metadata.
